# QuickNotes App

QuickNotes is a responsive, single-page note-taking web application built using vanilla HTML5, CSS3, and modern JavaScript (ES6+). It enables users to create, search, categorize, and store short notes directly in their browser.

## Features
- **Categorized Note Creation**: Add notes categorized as Personal, Work, or Study with visual color indicators.
- **Input Validation**: Prevents blank entries and limits notes to 200 characters with dynamic error messaging.
- **Realtime Search**: Filters notes dynamically as you type without page reloads.
- **Local Persistence**: Saves all notes to `localStorage` so data remains available across browser sessions.
- **Responsive Layout**: Adapts cleanly across mobile and desktop displays using CSS Flexbox.
- **Clear All Option**: Allows clearing all stored notes after prompt confirmation.
